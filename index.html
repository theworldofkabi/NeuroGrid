Adaptive Spike Encoding

Each new reading is compared against the previous one. Large changes become a high-priority event, small changes a low-priority event, and steady values are dropped to almost nothing — the same idea neuromorphic sensors use to save bandwidth.

HIGH SPIKE
A sensor value changed sharply since the last reading — e.g. soil moisture dropping fast during a dry spell.
LOW SPIKE
A small, ordinary change — normal drift that's still worth a lightweight event.
NO SPIKE
No meaningful change — nothing new to transmit.
